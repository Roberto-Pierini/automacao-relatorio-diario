# Automação de Relatório Operacional Diário

## Visão Geral
Projeto destinado a otimizar e automatizar a rotina diária de preenchimento do relatório de serviço.

## Problema
Atualmente, o processo exige a edição manual de três planilhas distintas no Excel Online, a captura manual de telas das seções correspondentes à data de execução e a colagem dessas imagens em um documento do Word Online[cite: 1]. Essa rotina repetitiva consome tempo operacional que pode ser otimizado via software.

## Objetivos e Requisitos
- **Edição de Planilhas:** Atualizar automaticamente as três planilhas operacionais com base na data do dia[cite: 1]:
  - Checklist de Carregamentos dos Eventos[cite: 1]
  - Checklist de Ferramentas[cite: 1]
  - Checklist de Operacionalidade da Fibra Óptica[cite: 1]
- **Captura de Evidências:** Obter uma captura de tela da área alterada que representa a data trabalhada[cite: 1].
- **Consolidação do Relatório:** Inserir a captura gerada diretamente no documento de relatório correspondente àquela data[cite: 1].

## Status do Projeto
- Em fase de alteração dos dados da planilha.
